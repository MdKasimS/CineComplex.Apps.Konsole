# CineComplex — From Console Application to Multitenant SaaS

## 📌 Project Overview

CineComplex began as a **modular monolithic console application** implementing core operations for three primary user groups: **Users, Administrators, and Partners**.

This project laid the foundation for my understanding of web applications, mobile applications, and desktop software. It helped me develop a strong grasp of software design patterns, architectural principles, and software versioning.

Building on these fundamentals, I evolved CineComplex into a **multitenant SaaS application**, demonstrating how a foundational application can grow into a comprehensive, distributed software system.

## 🚀 Technical Expertise Demonstrated

CineComplex serves as an engineering playground for exploring the following technologies, patterns, and practices:

1. **Backend Development:** ASP.NET Core Web APIs, C#, and Entity Framework Core.
2. **Software Architecture:** Modular monoliths, microservices, Clean Architecture, and Domain-Driven Design (DDD).
3. **Design Patterns:** Repository, Unit of Work, CQRS, Mediator, and other appropriate patterns.
4. **Event-Driven Architecture:** Apache Kafka and asynchronous communication.
5. **API Communication:** RESTful APIs and gRPC.
6. **GraphQL:** Efficient data retrieval for dashboards and client applications.
7. **Frontend & Client Development:** React, Angular, ASP.NET MVC, Blazor, .NET MAUI, and WPF.
8. **DevOps & Infrastructure:** Docker, Kubernetes, CI/CD pipelines, and Terraform for Infrastructure as Code (IaC).
9. **Testing:** xUnit, Moq, and integration testing with `TestServer`.
10. **Application Security:** OWASP security practices, JWT authentication, role-based authorization, and data protection.
11. **Database Technologies:** SQL Server, PostgreSQL, MongoDB, and Redis.
12. **Observability:** Structured logging and monitoring using Serilog, Seq, and Prometheus.
