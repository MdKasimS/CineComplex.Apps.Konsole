This repo is a console application - a modular monolithic application for all operations needed by User, Admin and Partner client.

For me, this formed the base to understand world of Web, android apps and desktop applications.
This helped me to understand design patterns, software architectures, and software versioninig.

Such robust fundamanetals helped me to build rich variant of CineComplex - SaaS application with multitenancy.
It demonstrates skills & concepts as :

1. Web API development using .NET Core, C#, and Entity Framework Core.
2. Microservices architecture with appropropriate design patterns like Repository, Unit of Work, CQRS, Mediator, etc.
3. Event-driven architecture with Kafka
4. API communication using REST and gRPC
5. GraphQL for optimized Dashboard
6. Frontend development using React, Angular, ASP.NET MVC, Blazor, MAUI and WPF.NET
7. DevOps using Docker, Kubernetes, CI/CD, Kubernetes and Terraform for IaC.
8. Testing using xUnit, Moq, and integration testing with TestServer.
9. Security best practices including OWASP, JWT authentication, role-based authorization, and data protection.
10. Strong hands on experience with SQL Server, PostgreSQL, and NoSQL databases like MongoDB and Redis.
11. Logging and monitoring using Serilog, Seq, and Prometheus.
